

# Python Classes

This project is part of the ALU Higher Level Programming curriculum.

## Description

This project introduces Object-Oriented Programming (OOP) in Python by implementing a `Square` class through several tasks. The project covers:

- Creating Python classes
- Private instance attributes
- Input validation
- Getters and setters using properties
- Instance methods
- Calculating the area of a square
- Printing objects
- Working with object position

## Requirements

- Ubuntu 20.04 LTS
- Python 3.8.5
- No imported modules
- Files must be executable
- Code must follow `pycodestyle` (version 2.7.*)
- Every module, class, and method must contain documentation.
